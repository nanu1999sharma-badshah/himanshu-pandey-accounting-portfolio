# Himanshu Pandey Accounting Portfolio

A clean, modern portfolio website for Himanshu Pandey, an accounting executive. Built as a professional static site with responsive sections for expertise, highlights, services, and contact information.

## Project Structure

- `index.html` – main portfolio page
- `styles.css` – full styling and responsive layout
- `script.js` – interactivity and dynamic footer year
- `assets/` – visual assets and branding
- `README.md` – project overview and usage guide

## Run the website locally

Open `index.html` directly in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization

Update the contact details, experience sections, and company information in `index.html` and `styles.css` to match the actual profile and brand.
